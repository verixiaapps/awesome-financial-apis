# Awesome Financial APIs 💰

Curated list of free and freemium APIs for financial data, stock markets, crypto, and economic indicators.

## Free Government APIs (No API Key)

| API | Data | Auth | Toolkit |
|-----|------|------|---------|
| [SEC EDGAR](https://www.sec.gov/edgar/sec-api-documentation) | US company filings & financials | User-Agent | [Python](https://github.com/spinov001-art/sec-edgar-api-python) |
| [Treasury FiscalData](https://fiscaldata.treasury.gov/api-documentation/) | National debt, exchange rates | None | [Python](https://github.com/spinov001-art/treasury-api-python) |

## Free APIs (API Key Required)

| API | Data | Free Tier |
|-----|------|-----------|
| [FRED](https://fred.stlouisfed.org/docs/api/fred/) | 816K+ economic series | Unlimited | 
| [Alpha Vantage](https://www.alphavantage.co/) | Stock prices, forex, crypto | 25 req/day |
| [Twelve Data](https://twelvedata.com/) | Real-time & historical stock data | 800 req/day |
| [Polygon.io](https://polygon.io/) | US stock market data | 5 req/min free |
| [Finnhub](https://finnhub.io/) | Stock prices, news, financials | 60 req/min |
| [CoinGecko](https://www.coingecko.com/en/api) | Crypto prices, market cap | 10-30 req/min |
| [Open Exchange Rates](https://openexchangerates.org/) | Currency exchange rates | 1000 req/mo |
| [BLS](https://www.bls.gov/developers/) | Employment, wages, prices | Unlimited |

## Use Cases

- **Stock Research** — SEC EDGAR + Alpha Vantage
- **Economic Analysis** — FRED + BLS
- **Crypto Trading** — CoinGecko + Finnhub
- **Forex** — Open Exchange Rates + Twelve Data
- **Portfolio Tracking** — Polygon.io + SEC EDGAR
